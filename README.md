# CodeFarm

Jogo educativo de fazenda para aprender lógica de programação na prática, com níveis e conquistas.

🔗 **Demo:** https://bertmartins.github.io/CodeFarm/

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/CodeFarm.git
cd CodeFarm
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
